# 🎬 YouTube Clone (HTML & CSS)

This is a simple YouTube clone project built using only **HTML** and **CSS**.  
It replicates the YouTube homepage layout and styling.

---

## 🚀 Features

- Responsive design for different screen sizes  
- Video thumbnails with titles and channel info  
- Search bar UI  

---

## ⚙️ How to Run

Open the `index.html` file in any modern web browser to view the project.
